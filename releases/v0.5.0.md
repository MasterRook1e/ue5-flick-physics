# Flick Physics v0.5.0

A portable source release that adds deterministic impact evidence and causal attribution to
the existing drag-to-launch, trajectory, replay, motion, and lifecycle contracts.

## Highlights

- relative, normal, and tangential contact speed
- contact alignment, reduced mass, directional momentum, normal kinetic energy, and impulse
- independent metric dead zones, normalization ranges, weights, and response curves
- bounded response scaling without embedded damage, team, score, or turn policy
- stable root, immediate-source, carrier, action, generation, and chain-depth provenance
- bounded provenance transfer with stale-carrier and malformed-input rejection
- team-independent source selection using mass-weighted directional motion
- configurable ambiguity and minimum-momentum rejection
- optional arbitrary-plane projection for planar or tabletop interactions
- canonical unordered body-pair keys for host-side callback deduplication

## Verification

The portable release gate compiles the C++17 core, CLI, benchmark, focused regressions, and
fixed-seed property suites with strict warnings. The release workflow repeats repository
boundary validation, enables AddressSanitizer and UndefinedBehaviorSanitizer, runs CTest,
installs the CMake package, and builds a separate external consumer.

The property evidence includes:

- 50,000 launch cases
- 10,000 lifecycle sequences
- 10,000 impact pairs

The source packager runs twice and the workflow rejects byte differences. The final release
attaches the deterministic source archive, SHA-256 checksum, and GitHub build-provenance
bundle.

## Compatibility and scope

The portable C++17 API is additive. Existing launch, trajectory, packet, motion, lifecycle,
CMake target, and reflected Unreal interfaces remain unchanged. Consumers may request:

```cmake
find_package(FlickPhysicsPortableCore 0.5 CONFIG REQUIRED)
```

Impact attribution is portable-first in this release. No reflected Unreal impact wrapper is
claimed, and no named Unreal Engine version is described as verified. A named engine claim
still requires a public `RunUAT BuildPlugin` result and executed `FlickPhysics` Automation
Tests recorded in `docs/COMPATIBILITY.md`.

This release contains no characters, factions, levels, combat rules, balance data, maps,
art, audio, credentials, private configuration, proprietary assets, engine source, or
private product history. It is a source release, not an engine-built binary package.

See `docs/IMPACT_ATTRIBUTION.md`, `docs/PORTABLE_CORE.md`, and `docs/RELEASING.md` for the
behavior and evidence boundaries.
