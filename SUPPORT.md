# Support

Use GitHub issues for reproducible defects and narrowly scoped feature proposals.

A useful defect report includes:

- Unreal Engine version or portable compiler/CMake versions
- operating system and architecture
- minimal synthetic code or project setup
- exact settings and inputs
- expected result, actual result, and logs
- whether the portable test path or Unreal path is affected

Do not attach proprietary projects, engine source, credentials, or private assets. General
game-development consulting and debugging of unrelated host systems are outside project
support.

The project is community-maintained and provides no response-time or compatibility SLA.
