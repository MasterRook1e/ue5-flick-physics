# Code of conduct

Participants are expected to communicate professionally, criticize ideas rather than
people, provide reproducible technical context, and respect privacy and intellectual
property.

Unacceptable conduct includes harassment, discriminatory language, threats, deliberate
publication of private material, spam, fabricated project metrics, and knowingly false
security or compatibility claims.

Report conduct concerns privately to the maintainer through an appropriate GitHub channel.
The maintainer may edit, hide, lock, or remove contributions and restrict participation
when needed to protect contributors and the project.
